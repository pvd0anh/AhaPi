## Place Value First

Every digit in a decimal number has a value that depends on its position.

| Digit position | Value | Example in $34.752$ |
|---|---|---|
| Tens | $10$ | $3$ means $30$ |
| Ones | $1$ | $4$ means $4$ |
| Tenths | $\frac{1}{10}$ | $7$ means $0.7$ |
| Hundredths | $\frac{1}{100}$ | $5$ means $0.05$ |
| Thousandths | $\frac{1}{1000}$ | $2$ means $0.002$ |

## Adding Decimals

The whole method rests on one rule.

> **Line up the decimal points.** Everything else is ordinary column addition.

**Worked example.** $12.4 + 3.75$

Write the numbers with the points underneath each other, filling short numbers with a zero so both have the same number of decimal places:

$$\begin{array}{r} 12.40 \\ +\ 3.75 \\ \hline 16.15 \end{array}$$

Adding a zero on the right does not change a decimal's value, because $12.4 = 12.40$. It only keeps the columns tidy.

### The common mistake

Lining up the **right-hand edges** instead of the points. That would pair the $4$ tenths with the $5$ hundredths and produce nonsense. Position, not appearance, decides which digits add together.

[[BÀI TẬP]]

[[Câu]] Work out $8.6 + 4.35$.
[[Đáp án]] Write $8.60 + 4.35$. Adding column by column gives $12.95$.

[[Câu]] Work out $0.7 + 0.45 + 1.2$.
[[Đáp án]] Write them as $0.70 + 0.45 + 1.20 = 2.35$.

[[Câu]] A student writes $5.3 + 0.28 = 5.58$ by lining up the last digits. Is the answer right? Explain.
[[Đáp án]] The answer $5.58$ is correct, but only by luck of the digits. The safe method is $5.30 + 0.28 = 5.58$ with the points aligned. Lining up the right-hand edges fails as soon as the whole-number parts have different lengths, for example $5.3 + 12.28$.
